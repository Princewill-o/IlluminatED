# Supplied Blocky character collection

Source: the three user-supplied `Blocky-Characters-FREE-Sample-8` folders, by Popyca / Vuena. The supplied README and LICENSE describe the characters as CC0. Original licence notices remain beside the models.

The first and `-8-2` folder contain byte-identical v1.1 GLBs: eight characters, each with ten animations. The `-8-3` folder contains eight distinct classic character files with six original animations. The platform offers these sixteen unique designs, preserving the original face, hair and mesh silhouettes.

Classic rigs use the same 22 Mixamo-named bones as the current files. The renderer uses compatible clips from the supplied v1.1 hero to provide all ten preview actions on classic designs too. The previous Rose Princess entry was a duplicate of Classic Princess; saved Rose Princess choices map to Classic Princess.

Default palettes remain authored. Explicit outfit, legwear and footwear dyes recolour the shared atlas only where skinned triangles predominantly belong to those garment regions. These controls change colour, not garment shape. Cape, label, eyewear and hand equipment attachments are generated in the app and follow the supplied rig. Selecting a different head now selects a complete supplied character; old KayKit, animal and unknown head IDs normalize to City Hero.

Local-only preview saves use `illuminated:preview-avatar:v1`. Only free cosmetics are accepted by that helper. Production save, purchase and ownership checks continue through the existing account actions.
